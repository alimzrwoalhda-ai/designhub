# DesignHub Arabic

منصة عربية مجانية لرفع ومشاركة وتحميل التصاميم والقوالب الجاهزة، مبنية باستخدام PHP Native مع PDO و MySQL و Bootstrap 5.

## طريقة التشغيل على XAMPP

1. انسخ مجلد المشروع إلى:
   `C:\xampp\htdocs\designhub`
2. شغل Apache و MySQL من لوحة XAMPP.
3. افتح phpMyAdmin وأنشئ قاعدة البيانات عبر استيراد ملف:
   `database.sql`
4. افتح الموقع:
   `http://localhost/designhub`

## بيانات الأدمن التجريبية

- البريد: `admin@designhub.test`
- كلمة المرور: `admin12345`

## أهم المميزات

- تسجيل ودخول المستخدمين.
- رفع تصميم مع صورة معاينة وملف قابل للتحميل.
- تصنيفات وبحث.
- صفحة تفاصيل التصميم والتعليقات.
- تتبع المشاهدات والتحميلات.
- لوحة تحكم للمستخدم.
- لوحة أدمن لإدارة المستخدمين والتصاميم والأقسام.
- حماية باستخدام `password_hash` و Sessions و CSRF و PDO و File Validation.
- تصميم عربي RTL متجاوب مع Light/Dark Mode.

## ملاحظات

- إعداد الاتصال بقاعدة البيانات موجود في `includes/db.php`.
- صيغة الرفع المسموحة للمعاينات: `jpg, jpeg, png, webp`.
- صيغة ملفات التصميم المسموحة: `zip, rar, pdf, psd, ai, fig, xd, pptx`.
